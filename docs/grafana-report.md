# Grafana 双语运行汇报

- [中文 · 网络运行简报](http://192.168.20.169:3000/d/eve-aiops-report/network-operations-report)
- [English · Network Operations Report](http://192.168.20.169:3000/d/eve-aiops-report-en/network-operations-report)

顶部 **语言 / Language** 下拉菜单切换中文、英文，保留设备筛选和所选时间。
标题、说明、摘要口径、状态映射、图例及表头均翻译；设备名称、软件版本、
协议缩写和原始设备状态标签保留原值。Grafana 本身的导航语言由用户个人设置控制。
在地址后加 `?kiosk` 可用于投屏。

原有 `eve-aiops-overview` 运维面板保持不变。两个语言版本使用同一生成器和
同一组计算规则，未增加设备连接、采集任务或更改拓扑布局。

## 汇报内容

每种语言包含 55 个面板（含说明与分组），首先给出摘要，再提供依据。

- 总览：可达 / 不可达设备、最近采集成功比例、Nautobot 同步时效、状态趋势、软件版本横向条形图。
- 自动运行总结：设备、采集、CPU、内存、BGP、OSPF、VXLAN、硬件部件、接口的观测量与待核查量；每行注明统计单位与判断规则。
- 覆盖与数据质量：14 类指标的覆盖设备数、未识别硬件状态、未识别路由来源、无效容量百分比、同步结果 / 耗时 / 接口数、最慢设备采集耗时。
- 资产与容量：CPU / 内存排行、硬件容量排行与已用 / 可用 / 总量、型号分布、设备状态与运行时长、内存总量与可用量、硬件状态汇总。
- 路由与邻居：BGP / OSPF / VXLAN 趋势，设备与 VRF 的路由规模、路由分类、BGP 收到 / 接受 / 发送路由按地址族的汇总及消息计数。
- 防火墙：覆盖设备、活跃会话、会话建立速率、吞吐及趋势；不据此推断安全事件。
- 接口（最后）：状态、待核查接口、收发流量排行、最高单接口流量趋势、十类错误 / 丢弃计数器的总结与明细。

可按右上角时间段和设备范围筛选，默认最近 24 小时、每分钟刷新。
Nautobot 同步四项为全局指标，其他指标跟随设备范围。

## 计算口径

- 卡片取所选时间终点的最近观察值，趋势反映已有样本；最近采集成功比例不是业务 SLA 或时段可用率。
- 所有查询都以 Agent 的 Prometheus `up == 1` 为条件。抓取失败时留空；并不能仅凭端点可访问证明内部采集循环在推进，需结合同步时效判断。
- 可选设备指标仅采用最近采集成功设备的观察。导出器仍可能保留旧的可选字段 / 状态标签，不能把它们视为实时配置清单。
- 没有指标时显示“暂无数据 / No data”；覆盖表的 0 明确表示未收到当前可用序列，不据此认定功能未配置。摘要内部用 -1 表示未知，再映射为灰色文字，避免误报正常。
- BGP 按设备 / 邻居 / VRF、VXLAN 按设备 / 对端去重；这些是观察端点数，不是物理链路数。存在冲突状态时保守取较低状态，需人工确认。
- 硬件仅对明确的 adverse 状态标签统计待核查部件；其他未知标签单列数据质量。无电源、未安装、不支持等状态不直接算故障。原始状态表按记录汇总，不能当作唯一部件数量。
- ASIC / TCAM 首选 telemetry、以 CLI 补充。使用率须在 0–100% 内才进入排行；越界值另行计数，不截断伪装成正常值，也不在本次修改采集解析器。
- 型号字段中出现 `sw-version` 或空值时归为未识别。路由总量只采用 `Total Routes`，分类只接受明确的路由来源；解析异常标签从分类汇总剔除。
- 各设备 / 邻居 / VRF 可重复观察同一路由或流量，汇报不将其解释为全网唯一路由、唯一业务吞吐或唯一会话。防火墙会话相加明确标为观察合计。
- 接口 admin-up / oper-down 可能是空闲未接线端口。错误 / 丢弃是原始累计计数，非所选时段新增事件；十类计数器不相加推断独立故障。
- CPU / 内存 / 容量 80% 为参考提醒、95% 标红；同步 5 分钟提醒、15 分钟标红。仅用于展示，不创建告警策略。

## 维护和部署

编辑 `scripts/grafana/build_report.py` 后运行：

```sh
python3 scripts/grafana/build_report.py
python3 scripts/grafana/build_report.py --check
```

输出 `grafana/dashboards/aiops-report.json` 和 `aiops-report-en.json`。
不要分别手工维护两份 JSON。两个 dashboard 带 `aiops-report-language` 标签，
Grafana 原生 dashboard-link 下拉菜单按此标签列出两种语言；不需要插件或浏览器脚本。

将 JSON 同步到服务器 repo 目录及 `/var/lib/grafana/dashboards/`。
现有 provisioner 每 30 秒加载，不需要重启 Grafana 或采集 Agent。
部署前备份汇报文件；回退只恢复旧中文汇报并删除新增英文 JSON。
